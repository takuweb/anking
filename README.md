# RemindFlow - 忘却曲線ベースの自由記述暗記Webアプリケーション

ヘルマン・エビングハウスの忘却曲線および間隔反復（Spaced Repetition / SuperMemo SM-2）アルゴリズムに基づき、最小の学習時間で長期記憶への定着を最大化する暗記Webアプリケーションです。

---

## 🌟 主な機能と特徴

### 1. 📲 ユーザー認証不要！スマホ ⇄ PC 端末間データ引き継ぎ
アカウント登録やパスワード設定を一切行わずに、PCとスマホの間でデータを瞬時に引き継げます。

- **① 6桁のワンタイム同期コード ＆ QRコード**:
  - 送信端末で「スマホ同期」を開くと、ワンタイム引き継ぎコード（例: `849201`）とQRコードが表示されます。
  - 受信端末のカメラでQRコードをかざすか、6桁コードを入力するだけで瞬時にデータを引き継ぎ。
- **② 完全オフラインQRコード直接転送**:
  - 全暗記カードデータをLZ-Stringで高密度圧縮し、QRコードそのものにエンコード。
  - 外部ネットワーク通信を一切介さず、完全オフラインでカメラスキャンのみでデータ転送可能。
- **③ テキストコード共有**:
  - 圧縮コードをワンクリックコピーし、LINEやAirDrop、メール等で自分宛に送って貼り付けるだけ。
- **④ スマート・マージ機能**:
  - 引き継ぎ時に「上書き」または「既存カードとの統合（更新日時が新しい方を自動採用）」を選択可能。

### 2. 暗記項目の自由記述 & 管理機能
- **自由記述エディタ**: 「表面（問題・キーワード）」と「裏面（解答・解説）」を自由にテキスト入力。
- **リッチテキスト・Markdown対応**:
  - 見出し、太字、イタリック、箇条書き、番号付きリスト
  - コードブロック（Syntax表示）、インラインコード、テーブル、引用
  - エディタ入力時、2分割リアルタイムプレビュー＆Markdown補助ツールバー付き。
- **タグ・カテゴリ分類**: 科目や分野ごとにタグを設定可能。タグ別の絞り込みや特訓セッションに対応。
- **検索 & フィルター**: 全文検索、ステータス別（本日復習、未学習、定着中、マスター済み）フィルター、各種ソート。

### 3. 忘却曲線（間隔反復・SM-2）によるスケジュール自動管理
- **SM-2アルゴリズム採用**: SuperMemoのSM-2アルゴリズムに基づき、難易度係数（Ease Factor）と復習間隔（Interval）をカードごとに動的最適化。
- **4段階の定着度評価**:
  1. `もう一度 (Again)`: 忘却。セッション内再学習＆翌日再復習。
  2. `難しい (Hard)`: 苦労して思い出した。間隔を微増。
  3. `普通 (Good)`: 適切に想起できた。標準の間隔で次回スケジュール。
  4. `簡単 (Easy)`: 余裕で想起。間隔を大幅に伸ばし、難易度係数をアップ。
- **目安日数プレビュー**: 各評価ボタンに「1日後」「3日後」「6日後」「12日後」などの次回予定をリアルタイム表示。
- **今日の復習自動抽出**: 今日期日を迎えたカードを自動抽出し、ワンクリックでセッション開始。

### 4. 洗練されたクイズ・学習セッション
- **シンプルなフォーカスUI**: 問題を見て頭の中で考え、「答えを表示」で解答を確認。
- **爆速キーボードショートカット**:
  - `Space`: 答えを表示
  - `1`: もう一度 / `2`: 難しい / `3`: 普通 / `4`: 簡単
  - `Esc`: セッション中断
- **カードのその場編集**: 学習中に気づいた誤字や補足をワンクリックで編集可能。
- **セッション完了演出**: 完了時の紙吹雪（Confetti）演出、正答率・回答傾向サマリー表示。

### 5. ダッシュボード & 統計分析
- **忘却曲線 vs 間隔反復の視覚的グラフ**: エビングハウスの忘却曲線と反復効果をSVG図解。
- **今後7日間の復習予定予測**: 日ごとの復習カード枚数を棒グラフで可視化。
- **記憶定着ステージ分類**: 未学習 → 初期定着 (1〜7日) → 中期定着 (8〜20日) → 長期マスター (21日以上)。
- **ストリーク管理**: 毎日の連続学習日数をカウントしてモチベーションを維持。

## 🚀 起動方法とスマホでのアクセス

### 開発サーバーの起動
```bash
npm install
npm run dev
```

### スマホからのアクセス
送信側（PCまたはスマホ）で「スマホ同期」を開き、表示される **6桁コード** または **QRコード** を使って、同一Wi-Fiでも4G/5G回線からでもデータを瞬時に引き継げます。
